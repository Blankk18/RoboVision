Developed by **Om Nathwani**

This is the React 19 + TypeScript + Vite + Tailwind CSS engineering workstation interface for ROBOVISION QMS 4.0.

### Scripts
- `npm run dev`: Start Vite development server
- `npm run build`: Compile TypeScript and build production bundle into `dist/`
- `npm run preview`: Preview production build locally
